# 格式要求與來源判讀

本文件依專案內的 `format.pdf` 整理。已完整閱讀 PDF 的 18 頁文字，並逐頁檢視全部頁面影像，包括表格、圖 1–8、封面及前置頁與正文範例。以下「第 N 頁」一律指 **PDF 實體頁碼（1–18）**，不是該頁印出的頁碼。

來源首頁題名為「中正大學資訊管理研究所學位論文編排要點」，載有 2024/01/02 編輯及 2024/01/09 系務會議修正通過日期。格式依此檔案判定；未另外套用其他學校的論文格式。

本文件記錄**要求及判讀依據**，不代表輸出已通過驗證。實際編譯、字型、量測及目視結果請見專案的驗證紀錄。

## 1. 判讀類別

- **明定**：來源文字明確指定，或明確要求依附圖執行的格式。
- **示例**：來源用「例如」、範例內容或示意版面表達，並非所有數值與文字均為強制規定。
- **合理預設**：來源未指定，但為產出可使用的模板所需的選擇；不得冒充校方規定。
- **使用者裁定**：來源互有衝突，由使用者於 2026-09-24 指定本模板的採用方式。
- **人工處理**：模板可預留、引入或提示，但不能單靠編譯完成。

## 8. 合理預設及必須人工完成的部分

合理預設應在使用說明及驗證紀錄中保持一致：

1. A4、兩字段首縮排、未另定的誌謝標題樣式、正文公式章別編號、空白封底。
2. 圖示沒有數字的位置與尺寸，依範例安排並以實際輸出檢視；不捏造校方的毫米級標準。
3. 不強制奇數頁開章、不增加裝訂邊，不把來源的示例章名、101 級或壞掉的目錄連結帶入成品。
4. 1.5 行距的數值化解釋、字型斜體／粗體的處理方式應如實揭露，並由 PDF 字型與座標驗證支持。

人工責任：

- 取得學校指定的最新審定書，完成簽名後替換佔位頁；確認替換後的順序、頁碼與頁面尺度。
- 校對作者、指導教授、所別、學位、題目、日期及書背畢業級別，移除所有佔位資料。
- 校對中文作者姓氏筆劃排序鍵及全部引文資料；示例驗證不能保證日後新增文獻皆正確。
- 確認雙面列印、紙本裝訂、書背寬度與裁切。來源沒有指定的封面材質、顏色或其他送印要求應另向系所確認，不由模板杜撰。
- 修改內容、引入正式表單或改變字型後重新編譯並檢查最終 PDF。

**目前沒有尚待使用者裁定的來源衝突。** 校方審定書、實體簽章及裝訂仍屬人工事項；完成佔位機制不代表已完成這些事項。
